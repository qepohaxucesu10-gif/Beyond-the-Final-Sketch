# Reduced diffusion exploration

This directory is reserved for the reported reduced MLGLDM-inspired exploratory backbone notes: direct, Full25-process, and weak-process conditioning.

It is a reduced paper-inspired exploratory backbone and is **not** an official reproduction of MLGLDM. No Stable Diffusion 1.5, BBDM, pix2pix-Turbo, or other development branch is included in the public-release staging tree.
