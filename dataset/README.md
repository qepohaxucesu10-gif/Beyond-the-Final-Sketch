# Dataset access

CUFS provides the original face photographs. This project contributes the newly collected B01–B25 human drawing trajectories, which were created and curated by the School of Design Art, Xiamen University of Technology.

The public release will provide trajectory files, subject mappings, formal split definitions, stage-naming documentation, and release notes. Users may need to obtain the corresponding CUFS photographs separately from the original CUFS source, subject to its original access and redistribution terms. CUFS photographs are deliberately not included in this repository.
